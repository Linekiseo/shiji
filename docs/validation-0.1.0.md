## 交互验证

在 Android 15 / API 35、ARM64 模拟器上安装并启动应用，分别验证调试包与正式签名包：

- 首次启动为空白工作台，无演示任务。
- 系统键盘输入并保存文字；记录面板和保存按钮位于键盘上方。
- 调用系统相机拍摄、返回预览并保存为任务。
- 使用 Android 照片选择器选择图片，保存为该任务的进展附件。
- 请求麦克风权限、实际采集音频、停止并保存。33 秒的测试录音经媒体工具识别为有效 Opus 音频，48 kHz、单声道。
- 正式包另存一段约 3 分 56 秒录音；强制停止并重新启动应用，照片、图片及音频仍在详情中。音频播放后进度从 00:00 推进至 00:21，可暂停。
- 详情页可滚动查看上传图片和相机照片。
- 同一发布证书的 APK 覆盖安装成功，已有任务和 3 条进展保留。
- 包含图片和录音的完整备份成功生成 JSON，并交给 Android 系统分享面板；未向外部联系人或云盘发送测试内容。

浏览器正式构建另外验证文字记录、一层子任务、图片进展、父任务完成联动与重新打开、刷新后持久化。浏览器存储与 Android 存储分开，不包含设计稿中的用户数据。

## 验证范围

未连接安卓真机，未验证所有厂商系统的相机、麦克风音质和后台行为。以上播放验证指模拟器中的有效音频及播放进度，不代表真机拾音质量。语音转写和 AI 语义整理尚未实现，不属于此版本已有能力。

首次安装、换机或卸载前，可通过“更多功能 → 数据与备份”导出包含附件的完整备份。发布仓库不包含测试录音、拍摄内容、个人记录或签名私钥。
