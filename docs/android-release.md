# Android 0.1.0

拾迹的首个可安装 Android 版本。包名 `io.github.linekiseo.shiji`，最低 Android 9，目标 Android 16（API 36）。

## 正式版与设计稿的区别

- 独立 Android 容器，使用系统键盘、系统状态栏、返回键和原生滚动。
- 首次启动为空，不加载设计稿中的 152 条虚构任务。
- 本地时间替换演示固定日期，跨天自动更新“今天”。
- 应用私有文件夹保存任务、分类、草稿和附件；写入采用原子替换，图片、音频单独存储。
- 原生相机和照片选择器接入同一记录面板。录音使用设备麦克风，保存 Opus/WebM 附件。
- 导出交由 Android 分享面板，可以保存到用户选定位置；完整备份包含图片和音频内容，支持恢复。
- 移除固定 AI 整理样例，当前版本没有语音转写或 AI 服务。

## 权限与数据

首次录音请求麦克风权限，之后只在前台录音。切到后台会停止当前采集并保留录音草稿。图片由系统选择器授权；不申请读取全部媒体库、联系人、位置或通知权限。没有账户、云同步、广告或分析 SDK。

记录、照片和音频保存在手机应用私有目录。Android 自动云备份关闭，完整迁移使用应用内备份。卸载应用会清除本机记录。

## 签名与维护

GitHub Release 提供签名 APK 和 SHA-256 校验文件。正式签名密钥由维护者在仓库之外保存，仓库不包含密码或私钥。同一签名的后续 APK 可以覆盖更新并保留记录。自行编译的调试版本使用不同证书。
