# 拾迹 0.1.1

重新设计应用图标：使用 imagegen 生成折叠纸页形成的 S 形轨迹，采用蓝色玻璃质感与浅瓷色背景。

- 更新 Android 桌面图标、圆形图标、单色主题资源、启动页和应用内图标。
- 图标前景保留真正的透明背景，并适配 Android 自适应图标安全区域。
- 图标原图、透明前景、生成提示词和尺寸适配脚本一并开源。
- 包名及发布证书保持一致，版本号为 0.1.1（versionCode 2），可覆盖安装 0.1.0。

## 本机验证

- 图标生成通过 alpha 透明度与安全范围检查；主体最远点距中心 26.7 dp，处于 33 dp 安全半径以内。
- 5 项既有数据测试、TypeScript / Vite 构建、Android lintDebug、签名版本构建及 APK 签名校验通过。
- Android 15 模拟器覆盖安装成功，原有 1 个任务和 3 条记录保留。
- 实际查看了桌面圆形图标，点击后正常进入应用；“数据与备份”显示新图标及 0.1.1 版本号。

本版只更新品牌资源和版本信息。录音仍为音频附件，语音转写和 AI 语义整理尚未接入。
